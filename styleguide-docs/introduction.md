# Salon Management System - Component Library

Welcome to the Salon Management System Component Library. This living style guide provides interactive documentation for all reusable UI components used throughout the application.

## What is a Style Guide?

A style guide (or component library) is a curated collection of components that can be reused across your application. It serves as:

- **Documentation** - Visual documentation of all available components
- **Collaboration** - A shared reference between designers and developers
- **Consistency** - Ensures consistent UI/UX across the entire application
- **Efficiency** - Speeds up development by providing pre-built components
- **Testing** - Easy to test components in isolation

## How to Use This Guide

Each component in this guide includes:

- **Component Preview** - A live, interactive preview of the component
- **Props Documentation** - All available props with descriptions and types
- **Usage Examples** - Real-world usage scenarios and patterns
- **Variations** - Different states and configurations

Navigate through the sections using the menu on the left to explore the available components.

## Design Principles

Our components follow these principles:

1. **Simplicity** - Components should be easy to understand and use
2. **Reusability** - Components should be flexible and work in various contexts
3. **Accessibility** - All components should be accessible to all users
4. **Performance** - Components should render efficiently
5. **Maintainability** - Code should be clean and well-documented

## Technology Stack

This component library uses:

- **React** (^19.2.4) - UI library
- **TypeScript** - Type safety and better developer experience
- **React Bootstrap** - Bootstrap components for React
- **SCSS** - Styling with advanced CSS features
- **React Styleguidist** - Interactive documentation

## Component Categories

The components are organized into the following categories:

- **UI Components** - Basic, reusable UI building blocks
- **Layout Components** - Components for structuring page layouts
- **Form Components** - Form inputs and form-related elements
- **Data Display** - Components for displaying data
- **Feedback Components** - Components for user feedback and messaging

## Installation with Vite

This project uses Vite as the build tool. Components are built with:

```bash
npm install
npm run build
```

For development:

```bash
npm run dev
```
